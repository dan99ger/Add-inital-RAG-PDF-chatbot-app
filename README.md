# 🤖 RAG PDF Chatbot

An end-to-end Retrieval-Augmented Generation (RAG) application that allows users to upload PDF documents and ask questions based on their content using fast LLM inference.

---

## 📌 Features

* **PDF Document Processing:** Extract and chunk text from uploaded PDF files.
* **Vector Search:** Efficient document embedding and similarity search powered by **ChromaDB** and **Hugging Face Embeddings**.
* **Fast LLM Inference:** High-speed response generation via the **Groq API** and **LangChain**.
* **Interactive UI:** Simple and clean user interface built with **Streamlit**.

---

## 🛠️ Tech Stack

* **Language:** Python 3.11
* **Framework:** Streamlit
* **RAG Framework:** LangChain
* **Vector Database:** ChromaDB
* **Embeddings:** Hugging Face Embeddings
* **LLM Provider:** Groq API
